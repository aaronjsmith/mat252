Midterm 1 · data, graphs, design

Written: Q1 center/5NS/hist/shape (13) · Q2 z / mean / IQR (6) · Q5 experimental design (6). ALEKS: pop/sample, sampling, types, graphs, dot plot, study design.

μ (mu) = population mean  ·  σ (sigma) = population standard deviation  ·  x̄ (x-bar) = sample mean  ·  s = sample standard deviation  ·  n = sample size  ·  N = population size

Symbols · say them in English

  • μ mu · population mean
  • σ sigma · population SD
  • x̄ x-bar · sample mean
  • s sample SD
  • n sample size
  • N population size
  • z z-score (SDs from mean)
  • Σ capital sigma · sum
  • ± plus or minus (μ±σ)
  • ≈ approximately
  • Q1 Q3 1st / 3rd quartile
  • IQR Q3 − Q1
  • P(A) probability of A
  • P(A|B) A given B (conditional)
  • p binomial success chance
  • C(n,k) combinations “n choose k”

Parameter (μ, σ, N) = population. Statistic (x̄, s, n) = sample.

Data types

  • Quant. numeric (average it)
  • Categ. label (qualitative)
  • Discrete countable (goals, tables)
  • Contin. any value in an interval
  • ZIP/ID look numeric → categorical

Sampling

  • SRS every set of n equally likely
  • Stratified SRS from every group
  • Cluster all units in some groups
  • Systematic every k-th (random start)
  • Conven. whoever is easy to reach
  • Voluntary people choose themselves

Q5 · Experimental design

  • Explanatory what you set / compare (treatment)
  • Response the measured outcome
  • Treatment a condition; include a control
  • Experiment a treatment is imposed
  • Observ. just record — no assignment
  • Confound lurking factor mixed with treatment
Randomized block: split units into similar groups (blocks), then randomly assign treatments inside each block.
Explanatory → Block 1 / Block 2 → random to T1, T2, control → Response.
Why: grades 1 & 2 reading programs — if you ignore grade, one program might get extra 2nd graders (better readers). Block on grade, then randomize within each grade.

Completely randomized = one big random assignment (no blocks). Block when a known nuisance factor (grade, ward, day) would otherwise unbalance treatments.

Q1 · Center, 5NS, graphs

FormulaExcel
x̄ = Σx / n =AVERAGE
median = middle (sorted)even n: average two middles =MEDIAN
mode = most frequent =MODE.SNGL
range = max − min =MAX−MIN
IQR = Q3 − Q1 =QUARTILE.EXC
s = √[Σ(x−x̄)²/(n−1)] =STDEV.S

5-number: min, Q1, median, Q3, max. Outlier fence: 1.5×IQR below Q1 / above Q3.

  • Histogram / stemplot → 1 quantitative
  • Dot plot → each point is a case (same as a skinny hist.)
  • Bar / pie → categorical counts
  • Rel. freq. = count ÷ n
  • Skew follows the long tail
  • Right skew → mean > median
  • Left skew → mean < median
  • Symmetric → mean ≈ median

Q2 · Z-SCORE

z = (x − μ) / σ  ·  x = μ + zσ

μ (mu) = population mean. σ (sigma) = population SD. x = the data value. z = how many SDs x is from the mean (+ above, − below). |z| large → unusual.

Q6 · Empirical rule (mound-shaped)

From the meanAboutz
within ±1σ≈ 68%−1 to +1
within ±2σ≈ 95%−2 to +2
within ±3σ≈ 99.7%−3 to +3
each 0→1 side≈ 34%half of 68%
between 1σ and 2σ≈ 13.5%each side
below μ − 1σ≈ 16%z < −1
above μ + 2σ≈ 2.5%z > +2

Only if mound-shaped. Center tick is μ (mean). Each step is one σ (sigma, SD). Tail % = leftover after the middle band.

Q3 · Probability

FormulaExcel
P(A) = fav ÷ totalequally likely =fav/total
P(Aᶜ) = 1 − P(A) =1−pA
P(A and B) = P(A)·P(B)independent =pA*pB
P(A or B) = P(A)+P(B)−P(both) =pA+pB−pBoth
P(A | B) = P(A and B) / P(B)conditional · “given” =pBoth/pB

“Given B” = restrict to B’s row/column. Mutually exclusive: P(A and B)=0 so or = add.

Q4 · Binomial X ~ B(n,p)

n independent trials, two outcomes, constant p.

FormulaExcel
P(X=k)=C(n,k)pk(1−p)n−k =BINOM.DIST(k,n,p,FALSE)
P(X≤k) cumulative =BINOM.DIST(k,n,p,TRUE)
P(X≥1)=1−P(X=0) =1−BINOM.DIST(0,n,p,FALSE)
C(n,k)=n!/(k!(n−k)!) =COMBIN(n,k)
E(X)=np   Var=np(1−p) =n*p

Unusual if P < 0.05. Discrete E(X)=Σ[x·P(x)].
